# Age rating answer draft

## 推奨

現行機能だけなら4+相当を想定します。App Store Connectの2026年版質問票で最終確定します。

- violence、sexual content、profanity、drug/alcohol、horror、medical treatment: none
- user-generated content、chat、messaging、in-app social network: none
- advertising、unrestricted web access: none
- gambling、simulated gambling、contests: none
- loot boxes: no

Appleはloot boxを「購入によってrandomized virtual itemを提供するvirtual container」と定義して
います。つみべんのgold/prismは集中時間から無料で発生する見た目だけのvariantで、購入、換金、
交換、譲渡できません。Pro購入は抽選確率、保証、質量、機能価値を変えません。そのためloot box
には該当しないという判断です。

参照: [Age ratings values and definitions](https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions)

抽選とIAPの関係、share導線、外部linkを変更した場合は必ず再判定します。
