サポート・
お問い合わせ

不具合、使い方、購入の復元についてのご質問やご要望をメールで受け付けています。

メールで問い合わせる

返信に必要な範囲で、端末機種、OSのバージョン、つみべんのバージョン、発生した状況をお知らせください。集中テーマ、顧客名、案件名、データ書き出しファイル、認証情報、秘密鍵、署名資材などの機微な内容を送る必要はありません。送信内容の利用目的・保持・削除はプライバシーポリシーをご確認ください。

support@hinoshiba.com

不具合・機能提案

公開してよい内容はGitHub Issuesでも受け付けます。実際の集中記録、顧客名、案件名、個人情報をIssueへ掲載しないでください。

脆弱性・プライバシー漏えい

セキュリティ上の問題は公開Issueへ書かず、GitHub Private Vulnerability Reportingをご利用ください。最初の報告には実データ、書き出しJSON、認証情報、秘密鍵、証明書、署名資材を添付せず、影響するバージョン・パス・再現条件を機微でない範囲でお知らせください。

購入を復元する

自由な時間設定が反映されない場合は、アプリの購入画面にある「購入を復元」をお試しください。

データと権限

初回にiCloud同期またはこのiPhoneのみを選びます。Version 1.0では後から変更できず、このiPhoneのみのデータは自動でiCloudへ送られません。表示中の集中記録のリセットはアプリ内の「設定」から行えます。リセット以前の旧世代は同期競合を防ぐため残る場合があります。端末内の物理データはアプリの削除、iCloud側のアプリデータはAppleのiCloudストレージ管理から削除できます。別のオフライン端末は遠隔消去できないため、不要なインストールは各端末で削除してください。アプリのJSON書き出しは全11種類の出荷対象SwiftData保存データが対象ですが、再インポートできず、iCloud移行や機種変更時の記録継続には使えません。写真やFilesへ保存した書き出し、共有先へ渡した内容、送信済みメールは別途その保存先で削除してください。通知、写真への追加、モーションの許可は端末の「設定」からいつでも変更できます。瓶のdevice motionは表示中だけその場で利用し、保存・送信しません。モーションを許可しなくても瓶のタップと他の集中機能を利用できます。詳しくはプライバシーポリシーをご覧ください。

機種変更後に記録が見えない

初回に「iCloudで同期」を選んだ場合だけ、機種変更後も同じApple Accountで記録を続けられます。つみべんのiCloud利用が有効で通信できることを確認し、アプリを開いたまま少しお待ちください。起動・再開時のApple Account確認とiCloud同期には通信が必要で、同期は即時ではない場合があります。別のApple Accountや通信不可のときは安全のため記録領域を開きませんが、保存済みデータは削除しません。進行中タイマーを新しいiPhoneへ移すときは、表示される「このiPhoneで続ける」から引き継いでください。元のiPhoneがオフラインまたはロック中だと、古い終了通知が一度だけ届く場合があります。

初回に「このiPhoneのみ」を選んだ記録は別のiPhoneへ同期されません。Version 1.0のJSONは再インポートできないため、機種変更時の継続やiCloudへの移行には使えません。保存先を選び直すには、必要に応じて閲覧用にJSONを書き出した後、アプリを削除・再インストールします。削除すると以前のlocal記録は失われます。

GIFやハッシュタグがSNSへ入らない

共有先のSNSやアプリによっては、GIFを静止画へ変換したり、画像と一緒に渡した本文を省いたりする場合があります。共有画面の「本文をコピー」を先に押し、投稿画面へ貼り付けてください。GIFを受け付けない共有先では「静止画」を選べます。
