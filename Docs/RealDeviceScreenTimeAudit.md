# 実機スクリーンタイム監査

状態: 下記の範囲だけ完了です。10分到達による勉強gem・黒いgemの付与は**実機で不合格のまま**、
individual authorizationの取消・再許可は**人手が必要**なまま残っています。
2026-09-21に#9の起動不能を直したbuildで再試験が成立し、**不合格の理由が初めて実機の数字で特定できました**。
iOSは両方の利用窓で閾値到達を**実際に配送しており**（到達2件）、監視拡張がその2件とも
「認可が不明（`.notDetermined`）」として**黙って捨てています**（記録0件・拒否0件）。
つまり故障はOS側の配送でも登録でもなく、**拡張内の認可判定**です（「見つかった欠陥と修正」#10）。
#10はその後このブランチで修正しましたが、**修正後のbuildで実際にgemが付くことは未確認**なので、
10分到達の行は不合格のままにしてあります。
端末の「アプリとWebサイトのアクティビティ」はOFFですが、閾値はそれでも届いたので**原因ではありません**。
Simulatorの成功、unit test、UI testを実機確認の代わりにしません。Family Controlsのdistribution承認は
別のゲートで、この監査では取得も確認もしていません。

仕様は[ScreenTimeGems.md](ScreenTimeGems.md)、出荷条件は
[submission-checklist.md](../AppStore/submission-checklist.md)の「スクリーンタイム候補の配布前確認」を正本とします。

## 目的

Screen Time（Family Controls／DeviceActivity）の登録・停止を直列のバックグラウンドworkerへ移した変更
（`PomoGem/Core/ScreenTime/ScreenTimeMonitoringWorker.swift`、PR #24）について、Simulatorでは一度も動かない
経路を署名済みiPhoneで確認することが目的です。Simulatorでは許可が下りず台帳も結び付かないため、
登録処理そのものが走りません。次の4点を実機の証拠で区別することを狙いました。

1. 保存中も設定画面が止まらないこと（「反映中」行・戻る操作・保存の二重実行防止・登録の実測時間）。
2. individual authorizationの許可・取消・再許可と、取消後の表示。
3. 選択の上限と種別の拒否（無料5つ・6つ目拒否、カテゴリ／Web拒否、両側への同一アプリ拒否）。
4. 実際に10分使ったときに到達通知が届き、瓶へ差分だけが落ちること。

読み方は3点です。

1. **レーン用の区間開始が16件**あるので、当日の日付で作った**反復しない**登録でもiOSは区間を始めます。
   「区間が始まらないから何も起きない」という候補は**反証**されました。
2. **閾値到達が0→1→2**と、利用窓ごとにちょうど1件ずつ増え、時刻もそれぞれの窓の中に入っています。
   iOSは利用時間を測っており、**到達は届いています**。「アプリとWebサイトのアクティビティ」がOFFでもです。
3. その**2件とも「認可が不明」で捨てられ**、記録は0件、拒否も0件です。同じ時刻にアプリ側の画面は
   「アクセス許可済み」を表示しています。つまり**拡張のプロセスだけが認可を読み取れていません**（#10）。

保存前の読み出しには件数そのものが存在しません（台帳が一度も数えていない状態）。
これは「拡張が一度も起動していない」ことの証拠にはなりますが、保存前なので当然の値です。

  Console.appでsubsystem `com.hinoshiba.pomogem`を絞り込みます。`log stream`／`log show`には
  端末を指定するoptionが無いため、その2つでは端末の記録は読めません
- #8の件数は、#11の写し（アプリのコンテナのApplication Support配下）を保存前・保存直後・
  各利用窓の直後の4時点で取り出して保管しています。取り出しは読み取りのみで、端末側のfileは
  1バイトも書き換えていません。件数・真偽・時刻だけで、識別子・token・アプリ名・gem数は含みません
- 設定アプリのスクリーンタイム画面の読み取り（スクリーンショットと画面階層）も同じ場所に置いてあります。
  **閲覧のみで、切り替えは一切触っていません**
- 起動不能（#9）の根拠にしたアプリ自身のオフライン利用の受領書も、リポジトリの外へ取り出して
  保管しています。アカウントを識別できる値はこの文書にも作業記録にも書き写していません
