# 合計時間による結晶化

設計決定: 2026-10-11。計算・永続化、利用導線、独立検証の3エージェントと統合担当で検討・合意。
`EngagementArchitecture.md` と `GemExperienceDesign.md` の「10記録で結晶化する」画面仕様を本書で置き換える。

## 問題と比較した案

従来は時間に比例した質量を保存する一方、同じ保存階層のgemが10個そろうと結合していた。
そのため、10分を10回でも100分を10回でも1個の結晶になり、短いタイマーほど結合が頻発した。

| 案 | 評価 |
|---|---|
| 個数結合を維持し、説明と大きさだけ時間に変更 | 結晶の数・到達頻度に個数の影響が残るため不採用 |
| 合計250分を超えるまで元のgemを丸ごと集める | 100分×5回は300分結晶1個＋200分、10分×50回は250分結晶2個となるため不採用 |
| 250分を超えたら全体を常に1結晶へ集める | 公平だが、瓶に複数の結晶が積み上がる体験を失うため不採用 |
| 記録と表示を分離し、時間総額から正確な単位と剰余を導く | 同じ時間で数・格・端数が一致し、既存記録を保全できるため採用 |

## 確定したルール

- 入力は既存の保存済み集中時間の質量。1分=10g、最小結晶=250分=2,500g。
- `q = totalGrams / 2500` を10進分解し、各桁を250分、2,500分、25,000分…の結晶として表示する。
- `r = totalGrams % 2500` は「結晶になる途中」のgem1個へ。端数は切り捨てず、次の完走へ全額繰り越す。
- 500分は分割によらず250分結晶2個、600分は同2個＋100分。2,500分で上の大きさの結晶1個となる。
- 1回360分でも結晶1個＋110分になる。結合のための最低完走回数は設けない。
- 大きさ、カット、刻印はその表示gemの時間で決める。色は着地済みの取り組みの内訳を反映し、結晶になる途中のgemにも複数色を残す。各gemは合計時間の単位であり、色は特定の記録がそのgemに属することを示さない。
- 既存の分単位クレジットを変更しない。秒から分への換算、レア抽選、課金、手動入力の制限は別の既存仕様である。

## 操作の流れ

1. ホームは着地済みの時間を表示し、「次の結晶まであと○時間○分」から時間の内訳と元の記録へ進める。
2. 完走カードは今回の時間を先に伝える。カードを閉じてgemが落ちた後、その時間を一度だけ表示へ加える。同期中など、着地前の正確な総額が確定できない場合は表示への加算を推測せず、検証後の総額を待つ。
3. 時間単位を越えた着地だけ結晶化を祝う。同期、復元、履歴索引の整理では祝いを再生しない。
4. 祝いは「4時間10分が、ひとつの結晶に。」、合計時間、繰り越し時間を表示する。「休む」を維持する。
5. タップはgemを弾ませ、長押しで内訳を開く。結晶は時間総額を表す単位なので、内訳では全体の時間と元の記録を確認する。架空の「この250分に属するセッション一覧」は作らない。
6. 積み上がり、年月、将来のプレビュー、共有も同じ時間計算を使う。共有は非公開記録を除外した選択範囲の時間だけから描く。
7. 合計未確認・下限値では残り時間を推測せず、確認中であることを伝える。

## ホームの情報整理

- 瓶の常時表示は累計質量と瓶の杯数を中心にし、瓶の下は「次の結晶まで」の短いリンクにする。元の記録数はメニューで、重さの旅の詳しい比較もメニューで確認する。大きい文字でも同じ情報配置を使う。
- 中央の累計時間は、暗い円盤・時計・目盛りのある固定メーターで表す。動くgemと同じ宝石のカットや強い発光を使わない。時間・次の節目の計算は既存の集計を使い、下限値では不確かな進捗を描かない。
- 小型画面の内側HUDで、静止gemが中央メーターを覆う場合は、瓶の左右に空きがあれば盤面を寄せる。一度決めた側を保ち、落下や傾きには追従しない。gemの物理・大きさ・タップ領域は変えない。
- gemをタップすると弾み、長押しすると時間の積み上がりへ進む。旧形式の保存済み結晶は長押しで詳細シートを開く。VoiceOverでは内訳のカスタムアクションを使える。タイマーの選択欄を隠す中間カードは出さず、閉じた後も取り組みと時間を選べる。
- 同期確認中の但し書き、着地後の加算、VoiceOverの説明は維持する。
- 選択・管理画面では勉強と仕事の両方を含む「取り組み」を用いる。保存済みの名前・識別子は変更しない。
- iOS 26の通常文字・縦画面ではメニューを半高と90%高の間で動かし、最大化に伴う横幅の変化を避ける。大きい文字・横画面では全高のみとし、内容は縦スクロールする。背景を選ぶと半高へ戻す既存動作も維持する。

## 保存と互換性

`StudySession`、時間、元のUUID、レア結果を変更しない。保存済み`AggregatePebble`の10分岐の木も、
膨大な記録を限られた件数で読み込む履歴索引として維持する。表示の結晶とは別物であり、
新しい表示gemを保存集約の入力にしない。新しいCloudKit schema、データ移行、集約の解体は不要。

表示IDは専用namespaceで安定生成し、session IDs・件数・期間・テーマ内訳を捏造しない。
以前の個数結合の祝いは再表示しない。新しい時間の祝いは総額と検証世代を持つUI受領情報として保存する。

黒いスクリーンタイム石と記念石は集中時間へ加算しない。学習用スクリーンタイム記録・手動記録は
既存の個人瓶の集計方針を守る。共有では既存のプライバシーフィルターを先に適用する。

## リリース時の案内

時間の結晶は、複数の月にわたる合計時間を表すため、単一の「作った月」を持たない。
この表示では従来のPro月刻印は提供しない。祝いからの購入導線、Paywallの機能一覧と
旧導線からの購入完了文から月刻印の案内を外す。各集中の元の日付と月別記録は保持する。
Proの購入状態と、自由な集中時間・勉強アプリ数の拡張は変更しない。

公開中のサイト・App Storeの説明は公開バージョンに対応するため、この改修だけで書き換えない。
本仕様を公開するときは、リリースノートに月刻印の未提供を明記し、ストア・サイト・
スクリーンショットの月刻印に関するPro紹介も同時に更新する。
