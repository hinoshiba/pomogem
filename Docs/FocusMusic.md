# 集中用の音楽（Apple Music）

状態: 2026-09-26、`claude/focus-music`。タイマー画面の入口、選択シート、設定 → 集中 → 「集中用の音楽」まで。
Homeのメニューからの入口は、Homeの画面を変更中のほかの作業が終わってから追加します（同じ`FocusMusicSheet`を開きます）。

オーナー要望（F4）: 「Apple Musicのクラシックチャンネルとかをさっと出せるようなUI導線が欲しい」。

## 動き

- 集中・休憩タイマーの見出しの右側、回転アイコンの隣に音符アイコン（44 × 44pt、`timer.music`）を置きます。
  - Apple Musicが使えて音楽を選んであれば、タップで再生／一時停止します。
  - ミュージックアプリが再生中なら、登録状況に関係なく（確認中・確認できない・登録なしでも）タップで一時停止します。
    VoiceOverのラベルとアイコンは、タップで実際に起きること（一時停止・再生・選ぶ）に合わせます。
  - まだ選んでいない、許可や登録が必要などのときは、タップで「集中用の音楽」シートを開きます。
  - タップで再生を試して始まらなかったとき（案内が出た、登録や許可の状態が変わった）も、シートを開いて理由を見せます。
  - 長押し、またはVoiceOverのアクション「音楽を選ぶ」でも、いつでもシートを開けます。
  - 再生中はアイコンがスピーカーに変わり、アンバー色になります。
  - 集中・休憩の残り1秒になるとシートは（アニメーションなしで）閉じ、終わった後も開きません。
    終了アラートの「止める」ボタン、VoiceOverのフォーカス移動、Magic Tapがシートの下に隠れないようにするためです（#32）。
- 設定 → 集中の最後の行「集中用の音楽」（`settings.focus-music`）でも同じシートを開きます。行には選んだ音楽の名前
  （この起動中にシートがカタログの名前を読めていればその名前、読めていなければ下の一覧の名前、まだ選んでいなければ
  「未選択」）を出します。行を表示するだけでは許可を尋ねず、登録状況の確認やカタログの取得もしません
  （シートを開いたときに行います）。
- シートには、ミュージックアプリで再生することとApple Musicの登録が必要なこと、許可・登録の状態、
  再生中の曲名と再生／一時停止・次の曲、音楽の一覧、「集中を始めたら再生する」を表示します。
- 再生は`SystemMusicPlayer`で「ミュージック」アプリに任せます。ポモジェムは前面のままで、
  音楽を自分のaudio sessionで鳴らさず、Now Playingにもならず、`UIBackgroundModes`の`audio`も持ちません
  （瓶や完了の効果音用の`.ambient`のsessionは従来どおりで、ミュージックの再生を止めません）。そのため
  タイマー画面を離れず、アプリを離れたときの一時停止（F1）も起きません。
- 集中の画面から開いたシートには、アプリの外へ移るものを置きません。music.apple.comなどへのリンクはなく、
  許可が拒否・制限されているときも「設定」アプリを開くボタンの代わりに「集中が終わってから…」の説明だけを出します。
  「設定」アプリを開くボタンは、集中が動いていない画面（休憩の画面と設定の入口。後で加えるHomeの入口も同じ）から
  開いたときだけ出します。
- 集中や休憩が終わっても、終了アラームが鳴っても、音楽は止めません（2026-09-26の決定）。F5の終了アラームは
  鳴っている間だけ音楽を小さくする（duck）だけにする予定で、ミュージックアプリの再生はそのまま続きます。
- Proの機能ではありません（App Review 4.5.2／4.10）。

- 表示名はカタログから取得できればその名前（利用者のstorefrontの言語）、できなければ上の名前です。
  カタログの名前は許可済みのときに音楽の画面を開いて取得し、実行中のメモリだけに保持します。そのため
  設定の「集中用の音楽」の行は、起動後に一度音楽の画面を開くまで上の名前を出します。

  選択（保存しているID）は書き換えません。どれも再生できなければ、その旨を1行で表示します。
- Apple MusicのIDは予告なく変わることがあるため、毎回カタログから引き直し、`Playlist`／`Station`の値は保存しません。

## 状態と表示

| 状態 | シートの表示 |
|---|---|
| 未確認（`notDetermined`） | 「Apple Musicへのアクセスを許可」。このボタンか一覧のタップでだけ許可を尋ねます（一覧のタップは許可の後そのまま再生します） |
| 拒否（`denied`）・制限（`restricted`） | 理由と「設定」アプリを開くボタン（集中の画面からは説明だけ）。一覧は選んでおくだけで、再生の印（▶︎）を出しません |
| 登録なし（登録できる） | Appleの`musicSubscriptionOffer`（`.playMusic`のお試し・登録の画面。曲やプレイリストは指定しません）を開くボタン。再生・一時停止・次の曲のボタンは出さず、一覧のタップも登録の画面を開きます |
| 登録なし（登録できない） | 再生できない旨。一覧は選んでおくだけで、再生の印を出しません |
| 登録状況を確認できない | 再確認のボタン。一覧のタップでは再生も試し、始まれば「再生できる」として扱います（オフライン時や、MusicKit App Serviceが無効で登録状況を読めない場合に備えるため） |
| 再生できる | 再生中の曲名、再生／一時停止、次の曲 |
| 再生に失敗 | 「休憩のときなどに『ミュージック』アプリを一度開いてから…」の案内（iOS 26.4系の既知の不具合への対処） |

- 表示を開いたとき・タイマー画面を開いたときは状態を読むだけで、許可の画面を出しません。
- シートを開くたびに登録状況を確認し直しますが、確認中も前の答えを使い続け（一覧のタップはすぐ再生）、
  確認に失敗しても分かっている答え（再生できた実績を含む）を捨てません。確認できて答えが変わったときだけ更新します。
- 許可があれば、登録状況に関係なく、ミュージックアプリが再生中・一時停止中の音楽を一時停止・再開・次の曲で
  操作できます（ミュージックアプリの標準の操作で、再生する内容は入れ替えません）。
- 同時に来た確認（シートを開いた直後のタップ、起動直後の自動再生など）は1回の確認を共有し、
  どの呼び出しも答えが出た後の状態を読みます。
- 再生を始める間はほかの操作を受け付けませんが、一時停止だけはいつでも受け付け、始まった再生も止めます。
  MediaPlayerの準備（`prepareToPlay`）が10秒たっても終わらないときは失敗として案内を出します。

## 集中を始めたら再生する（任意・既定はオフ）

- オンのとき、このiPhoneで集中を始めた直後（開始から15秒以内）に、選んだ音楽を1回だけ再生します。
- 許可や登録が必要な状態では何もしません（許可を尋ねず、登録画面も出しません）。
- ミュージックアプリでもほかのアプリ（ポッドキャスト、ほかの音楽アプリなど）でも、音楽や音声がすでに
  再生中なら入れ替えません（`AVAudioSession`の`isOtherAudioPlaying`を読むだけで、sessionの設定や有効化はしません）。
- 復元・再開・画面の作り直しでは再生しません。iCloudで別のiPhoneから引き継いだ集中は、始まった直後でも
  再生しません。同じ集中で2回目は再生しません（最後に自動再生した集中のIDを保存しています）。
- 登録状況を確認できないときも再生しません（推測で再生しません）。

## 保存するもの

このiPhoneのUserDefaultsだけに保存し、iCloud同期・JSON書き出し・保存先の移行には含めません。

| キー | 内容 |
|---|---|
| `music.focus.source` | 選んだ音楽のApple Music ID |
| `music.focus.autoplay` | 「集中を始めたら再生する」 |
| `music.focus.autoplay.last-session` | 最後に自動再生した集中のID（同じ集中で二度鳴らさないため） |

内部の完全削除処理では、ほかのUserDefaultsとともに消去し、この実行中に並べた音楽の記録も忘れます。
ミュージックアプリの再生は利用者のものなので止めません。曲名や再生状態は保存・送信しません。

## オーナーの作業が必要なこと

1. **MusicKit App Service**: Certificates, Identifiers & Profiles → Identifiers → `com.hinoshiba.pomogem`
   → App Services → MusicKitを有効にします（Account HolderかAdmin。Appleの審査なし、entitlementと
   provisioning profileの変更なし、Family Controlsのprofileに影響なし）。
   - 有効にするまでMusicKitのdeveloper tokenが発行されず、カタログの取得が失敗します。その間は
     `MPMusicPlayerController.systemMusicPlayer.setQueue(with: [ID])`でプレイリストだけを再生します
     （Appleは推奨していない方法です）。ステーション（クラシックステーション）は再生できず、次の候補へ進みます。
     表示名も上の日本語名のままです。

2026-09-26に決まったこと:

- `NSAppleMusicUsageDescription`の文言「タイマー画面から『ミュージック』アプリで集中用の音楽を再生するために使います。」は承認済みです。
- 一覧の内容と順序は上の表で確定です。
- 集中の終わりと終了アラームで音楽を止めません（F5はduckだけ）。
- 設定の入口を加えました。Homeの入口は後で加えます。
- Web版プライバシーポリシー（`http_dists/index.html`の`#privacy`、日本語と英語）に、ミュージックアプリの再生の操作だけで
  開発者へ何も送らないことを1文で加えました。

## テスト

- `PomoGemTests/FocusMusicTests`: 一覧と順序、方針（許可・登録・見出しのタップ・シートの再生／一時停止・一覧の再生の印・
  自動再生・シートを閉じる時点）、端末内の保存と削除、偽のplayer・許可・登録で動かす状態の変化
  （同時に来た確認の共有を含む）、`prepareToPlay`の待ち時間の上限、MusicKit／MediaPlayerのエラーの振り分け。
- `PomoGemUITests/AccessibilityAdversarialUITests/testAX5TimerHeaderMusicButtonPassesHitRegionAndClippingAudits`:
  AX5の集中中の見出しで、音符ボタンが44pt・画面内・隣と重ならず、Appleのhit region／text clipping監査に通ること。
- `PomoGemUITests/SettingsPaywallUITests/testTheFocusMusicRowOpensTheMusicSheet`: 設定 → 集中の「集中用の音楽」が
  選んだ音楽の名前を出し、タップで同じシートが開いて閉じられること。選んだ音楽は起動引数（argument domain）で与え、
  MusicKitの許可を尋ねず、Apple Musicのアカウントも使いません。
- `PomoGemUITests/SettingsPaywallUITests/testSettingsKeepsSupportPrivacyAndTheAboutPageTogether`と
  `testSettingsLayoutStaysReachableAtAccessibilitySize`: 標準とAX5の設定の順路で「集中用の音楽」の行が44pt以上で
  名前を保つこと。AX5では、中くらいの高さで開くシートの「閉じる」が押せ、最後の「集中を始めたら再生する」まで
  スクロールでき、大きい高さに広がった後の「閉じる」が44pt以上であること（許可のボタンと一覧の行は押しません）。
  iOS 26は中くらいの高さのシートを約96%に縮めて描くため、その高さでは縮めた分を差し引いて比べます。
  UIテストは毎回Simulatorを消去してから流します。前のテストが瓶の結果を残すとHomeの開始ボタンが押せず、
  タイマーが開かないまま失敗します（`main`でも同じです）。

## 実機での確認（Simulatorではできません）

iPhone 12 mini（iOS 26.3.x）で、Apple Musicの登録ありと登録なしのアカウントの両方で確認します。

- [ ] 初回タップでシートが開き、「Apple Musicへのアクセスを許可」でだけ許可の画面が出る

- [ ] 見出しのアイコンで一時停止・再開でき、ロック画面のNow Playingはミュージックアプリ
- [ ] App Service無効の状態でプレイリストが再生でき、ステーションは次の候補へ進む
- [ ] App Service有効後、ステーションが再生でき、表示名がカタログの名前になる
- [ ] 登録なしのアカウントでAppleの登録画面が開き、閉じた後に状態が更新される
- [ ] 拒否後、休憩の画面と設定 → 集中 → 「集中用の音楽」から開いたシートでは「設定」アプリを開くボタンが働き、
  集中の画面から開いたシートにはボタンがない
- [ ] App Serviceが有効で許可済みのとき、この起動中に一度音楽の画面を開くと、設定の「集中用の音楽」の行と
